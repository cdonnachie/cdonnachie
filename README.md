# Craig Donnachie

Open-source blockchain developer, infrastructure operator, and IT security leader.

I build and maintain blockchain software, wallets, explorers, mining infrastructure, and decentralized applications, with a primary focus on the [Avian Network](https://avn.network) and the wider UTXO ecosystem.

## What I’m working on

- Lead developer and maintainer for **Avian Network**
- Modernizing Avian Core on the Bitcoin Core codebase
- Building **FlightDeck**, a non-custodial Avian web wallet
- Developing blockchain explorers, asset tooling, mining software, and node utilities
- Contributing tools and infrastructure to the **Radiant** ecosystem
- Exploring post-quantum signatures, PSBT marketplaces, decentralized naming, and blockchain-based games

## Featured projects

| Project | Description |
|---|---|
| **Avian Core** | UTXO blockchain with dual proof-of-work, native assets, descriptor wallets, and modern Bitcoin Core foundations |
| **FlightDeck** | Non-custodial Avian wallet and progressive web application |
| **FlightPath Explorer** | Blockchain explorer and analytics platform for Avian |
| **Avian Node Helper** | Tools for installing, configuring, and maintaining Avian nodes |
| **Solo Stratum** | Lightweight solo-mining infrastructure for independent miners |
| **Radiant Tools** | Explorers, indexers, naming services, and applications for the Radiant ecosystem |
